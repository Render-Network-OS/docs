# The Invisible Engine

The **555x402 Protocol** is the "Invisible Engine" that powers the 555 Ecosystem. It is designed to be frictionless, verifiable, and crypto-native.

## Core Philosophy

Traditional streaming platforms (Twitch, YouTube) are **Black Boxes**. Creators don't own their audience, and advertisers can't verify engagement.

**555x402** changes this by introducing:
1.  **Verifiable Attention**: Proof that a user actually watched or played.
2.  **Direct Settlement**: Payments flow directly from Advertiser/User to Creator/Platform via Solana.
3.  **Audience Inventory**: Turning engagement into a tradable asset.

## Architecture

The protocol is built on **Solana** using the **Anchor** framework for maximum throughput and low latency.

### Components

| Component | Function |
| :--- | :--- |
| **VAP (Verifiable Attention Protocol)** | Verifies "Heartbeats" from client sessions to prove engagement. |
| **AGG (Aggregator)** | Routes 402 (Payment Required) requests to the best facilitator. |
| **Hyperlink** | A multi-chain payment link standard for creators. |

## The "402" Standard

We embrace the HTTP **402 Payment Required** status code. In our system, content is gated by default, and the protocol negotiates the payment (via micro-transactions, subscription, or ad-view) instantly and invisibly.
