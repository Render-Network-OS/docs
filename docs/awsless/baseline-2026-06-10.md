## Restored Alice Contract

Do not promote the AWSless rail unless these are re-proven on that rail:

- `/companion/` loads Alice, not a generic companion.
- Milady #9 VRM renders with the yellow hoodie avatar.
- Chat bar is present and usable.
- Action drawer/action pill opens.
- Avatar actions trigger visible motion.
- `/api/emotes` returns the restored action catalog; previous target was 41 emotes including `wave`, `agreeing`, `gangnam-style`, and `dance-happy`.
- Go Live modal supports setup, channels, mode, review, and vertical overflow.
- Truthful-live gating is based on Cloudflare Stream receiving media, not a local UI flag.
- Operator preview and live output remain the same composed program feed.

## Provider Split

- Railway: `555stream` control-plane, Postgres, Redis, public health route, internal origin networking.
- Cloudflare: DNS/WAF, Stream Live Input, Stream delivery, TURN/RealtimeKit, Workers, D1/KV/R2, optional Tunnel.
- RunPod: Alice worker/capture/render path only: Node, Playwright/Chrome, FFmpeg, VRM rendering, persistent Alice state volume if needed.
