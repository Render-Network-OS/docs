# Frontend Dashboard Prompt

Build the SW4P Earn proof dashboard. Do not make it a generic staking page.

Required design language:

```txt
- terminal-grade proof surface
- source-labelled economics
- health/status panels
- real/incentive/blended APY split
- no false green states
- clear stale/unknown/degraded banners
```

Required widgets:

```txt
- total 555 staked
- LP TVL
- real-fee APR
- incentive APR
- blended APR
- active epoch
- merkle root
- claimable amount
- fee source breakdown
- excluded volume
- supply invariant
- policy hash
- pause state
- last canary
```
